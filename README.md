# WinterPep 🧊

A comprehensive Data Structures & Algorithms practice repository in C++, covering fundamental concepts to advanced competitive programming techniques.

## 📁 Repository Structure

```
WinterPep/
├── Assignments/        # 100+ DSA problems (daily practice)
├── Contest/            # Competition problems
├── CP_DSA/             # Competitive programming topics
├── DSA/                # Topic-wise organized problems
└── DevOps/             # DevOps related content
```

## 📚 Topics Covered

## 🚀 Getting Started

### Prerequisites
- C++ compiler (g++ recommended)
- VS Code (optional)

### Compilation

```bash
# Compile a single file
g++ -o output filename.cpp

# Run
./output
```

Or use the VS Code build task (Ctrl+Shift+B) configured in `.vscode/tasks.json`

## 📖 Learning Approach

1. **Pattern Recognition** - Problems organized by patterns for better understanding
2. **Progressive Difficulty** - From basic implementations to advanced problems
3. **Topic Mastery** - Deep dive into each data structure with multiple problem variations
4. **Competitive Prep** - Dedicated section for competitive programming techniques
